# Recorded regression fixture

This directory contains one short, approved test clip and the data needed to
reproduce the current anatomical classifier output.

| File | Purpose |
|---|---|
| `cam4_05m38s-06m00s.mp4` | 22-second, 1280×720, 15 FPS RGB input for an end-to-end hand-pipeline check |
| `keypoints.json` | MediaPipe hand-pipeline output containing the 21 `joints_2d` points consumed by this classifier |
| `expected_results.json` | Output generated by the current classifier for regression comparison |

The expected results are **not manually annotated ground truth**. Matching them
shows that an integration preserves the current implementation; it does not
measure whether every label is correct. Accuracy evaluation still requires
human-reviewed frame or event labels.

The pure recorded-data test uses the JSON files and does not decode the video:

```bash
python -m unittest discover -s components/hand_open_close/tests -v
```

The MP4 is included so a receiving team can also run its own MediaPipe/ROS hand
pipeline and compare the resulting landmark stream. Exact floating-point
landmarks can vary with MediaPipe version and runtime backend, so compare hand
coverage and open/closed events rather than requiring byte-identical JSON.
